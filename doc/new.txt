# Mehfilista - Complete Flutter API Integration Guide

**Server:** `http://localhost:9000` (update for production)

This guide includes ALL features: location-based search, CNIC verification, approval workflow, pricing packages, and WhatsApp integration.

---

## 🎯 Quick Start Summary

### User Flow:

1. Get cities/areas → Register with location → Search vendors in area → View packages with cost calculator → Send inquiry → Chat on WhatsApp

### Vendor Flow:

1. Register → Upload CNIC → Set pricing packages → Wait for admin approval → Receive inquiries → Chat on WhatsApp

## 🔐 Authentication

### Register User

```dart
POST /auth/register

{
  "email": "user@example.com",
  "password": "password123",
  "name": "John Doe",
  "phone": "+923001234567",
  "role": "user",
  "city": "Karachi",      // REQUIRED
  "area": "Gulshan"       // REQUIRED
}

Response: { access_token, token_type, user }
```

### Register Vendor

Same endpoint, use `"role": "vendor"` (city/area optional for vendors)

### Login

```dart
POST /auth/login

{
  "email": "user@example.com",
  "password": "password123"
}
```

### Get Current User

```dart
GET /auth/me
Headers: Authorization: Bearer {token}
```

**Flutter Implementation:**

```dart
// Load locations for registration form
final response = await http.get(
  Uri.parse('$baseUrl/locations/cities-with-areas?active_only=true')
);
final List cities = jsonDecode(response.body);

// Build dropdowns

).toList();

// When city selected, show areas
final selectedCityAreas = cities
  .firstWhere((c) => c['name'] == selectedCity)['areas'];
```

**Flutter Implementation:**

```dart
);
```

```dart
// Show appropriate UI based on status

  case 'pending':
    return Text('Your account is under review');
  case 'approved':
    return VendorDashboard(vendor);
  case 'rejected':
    return Column(
      children: [
        Text('Your application was rejected'),
        Text('Reason: ${vendor['rejection_reason']}'),
        ElevatedButton(
          onPressed: () => updateVendorProfile(),
          child: Text('Resubmit'),
        ),
      ],
    );
}
```

```dart
final vendor = jsonDecode(await http.get(Uri.parse('$baseUrl/vendors/$vendorId')).then((r) => r.body));

// Display packages with cost calculator
class PackageSelector extends StatefulWidget {
  final Map vendor;
  // ...
}

class _PackageSelectorState extends State<PackageSelector> {
  String selectedPackage = 'basic';
  int numberOfGuests = 100;

  double calculateCost() {
    final package = widget.vendor['${selectedPackage}_package'];
    if (package == null) return 0.0;
    return package['base_price'] + (package['per_head_price'] * numberOfGuests);
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        // Package selector (Basic/Premium/Luxury)
        SegmentedButton(
          segments: [
            ButtonSegment(value: 'basic', label: Text('Basic')),
            ButtonSegment(value: 'premium', label: Text('Premium')),
            ButtonSegment(value: 'luxury', label: Text('Luxury')),
          ],
          selected: {selectedPackage},
          onSelectionChanged: (Set<String> selection) {
            setState(() => selectedPackage = selection.first);
          },
        ),
        
        // Package details
        Card(
          child: Padding(
            padding: EdgeInsets.all(16),
            child: Column(
              children: [
                Text(widget.vendor['${selectedPackage}_package']['description']),
                SizedBox(height: 8),
                Text('Base Price: PKR ${widget.vendor['${selectedPackage}_package']['base_price']}'),
                Text('Per Head: PKR ${widget.vendor['${selectedPackage}_package']['per_head_price']}'),
              ],
            ),
          ),
        ),
        
        // Guest count selector
        Row(
          children: [
            Text('Number of Guests:'),
            Spacer(),
            IconButton(
              icon: Icon(Icons.remove),
              onPressed: () => setState(() => numberOfGuests = max(1, numberOfGuests - 10)),
            ),
            Text('$numberOfGuests'),
            IconButton(
              icon: Icon(Icons.add),
              onPressed: () => setState(() => numberOfGuests += 10),
            ),
          ],
        ),
        
        // Total cost display
        Container(
          padding: EdgeInsets.all(16),
          color: Colors.green[100],
          child: Row(
            mainAxisAlignment: MainAxisAlignment.spaceBetween,
            children: [
              Text('Estimated Total:', style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
              Text('PKR ${calculateCost().toStringAsFixed(0)}', style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold)),
            ],
          ),
        ),
        
        // Send inquiry button
        ElevatedButton(
          onPressed: () => sendInquiry(),
          child: Text('Send Inquiry'),
        ),
      ],
    );
  }
}
```

```dart
  "event_date": "2024-06-15",
```

**Flutter Implementation:**

```dart
Future<void> sendInquiry() async {
  final response = await http.post(
    Uri.parse('$baseUrl/inquiries'),
    headers: {
      'Authorization': 'Bearer $token',
      'Content-Type': 'application/json',
    },
    body: jsonEncode({
      'vendor_id': vendorId,
      'event_type': eventType,
      'event_date': selectedDate.toString().split(' ')[0],  // YYYY-MM-DD
      'selected_package': selectedPackage,
      'number_of_guests': numberOfGuests,
      'message': messageController.text,
    }),
  );

  if (response.statusCode == 201) {
    final inquiry = jsonDecode(response.body);
    // Show success message with estimated cost
    showDialog(
      context: context,
      builder: (context) => AlertDialog(
        title: Text('Inquiry Sent!'),
        content: Text('Estimated Cost: PKR ${inquiry['estimated_cost']}'),
        actions: [
          TextButton(
            onPressed: () => openWhatsApp(vendor['whatsapp_number']),
            child: Text('Chat on WhatsApp'),
          ),
          TextButton(
            onPressed: () => Navigator.pop(context),
            child: Text('OK'),
          ),
        ],
      ),
    );
  }
}
```

## 💬 WhatsApp Integration

**No API endpoint - Direct link**

```dart
Future<void> openWhatsApp(String whatsappNumber) async {
  // Remove + and spaces from number
  final cleanNumber = whatsappNumber.replaceAll(RegExp(r'[^\d]'), '');
  
  final message = Uri.encodeComponent(
    "Hi! I'm interested in your services for my event."
  );
  
  final whatsappUrl = "https://wa.me/$cleanNumber?text=$message";
  
  if (await canLaunch(whatsappUrl)) {
    await launch(whatsappUrl);
  } else {
    // Show error
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Could not open WhatsApp')),
    );
  }
}

// Use in vendor details page:
FloatingActionButton(
  onPressed: () => openWhatsApp(vendor['whatsapp_number']),
  child: Icon(Icons.chat),
  backgroundColor: Colors.green,
  label: Text('Chat on WhatsApp'),
);
```

## 📝 Important Notes

### CNIC Format:

- Format: `XXXXX-XXXXXXX-X` (e.g., `42101-1234567-1`)
- Validate before submission

### Approval States:

- **pending**: Show "Under review" message
- **approved**: Enable full vendor features
- **rejected**: Show reason + resubmit option

### Cost Calculation:

```dart
totalCost = basePrice + (perHeadPrice × numberOfGuests)
```

### Date Format:

- Always use `YYYY-MM-DD` for event_date
- Use `DateFormat` from `intl` package

### WhatsApp Numbers:

- Store with country code: `+923001234567`
- Clean before opening: remove `+` and spaces

## 🎯 Complete User Journey Example

```dart
// 1. User opens app

final locations = await fetchLocations();
```
